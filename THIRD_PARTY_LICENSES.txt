2. Webster's Second International Dictionary — 英文字典 (English word list)
--------------------------------------------------------------------------
english-dict.txt is filtered from /usr/share/dict/words (Webster's Second
International Dictionary, 1934), which is in the public domain.


3. PIME — Windows 輸入法框架 (input method framework)
----------------------------------------------------
https://github.com/EasyIME/PIME — GNU LGPL 2.1

The Windows version runs as a module inside PIME. The Windows setup.exe
includes the unmodified official PIME installer (PIME-1.3.0-stable-setup.exe
from https://github.com/EasyIME/PIME/releases) and runs it when PIME is not
installed yet; the .zip package does not include PIME. PIME's source code is
at https://github.com/EasyIME/PIME/tree/v1.3.0-stable. Its license summary
is in PIME-LICENSE.txt and the GNU LGPL 2.1 text in LGPL-2.1.txt.

The experimental stand-alone Windows version (AutoZhuyin-Windows-Standalone-
<version>-setup.exe) does not use PIME. It includes the embeddable 64-bit
Python from python.org (PSF License; full text in python\LICENSE.txt) and
NumPy (BSD 3-Clause; in its .dist-info folder).


4. CKIP GPT2 Tiny Chinese — AI 選字語言模型 (language model)
-----------------------------------------------------------
https://huggingface.co/ckiplab/gpt2-tiny-chinese
https://github.com/ckiplab/ckip-transformers
Author: Mu Yang at CKIP, Academia Sinica (中央研究院 詞庫小組)
License: GNU General Public License v3.0 (full text: GPL-3.0.txt)

lm.bin is the model's weights converted to float16 by training/lm/export_lm.py;
lm-vocab.txt is its vocabulary (from bert-base-chinese). They are used unmodified
otherwise, to rerank conversion candidates ("AI 選字"). The source code of this input
method, including the conversion script and the code that runs the model, is
available from the project repository.


5. NumPy — 數值運算 (Windows / Linux, for AI 選字)
------------------------------------------------
https://numpy.org — BSD 3-Clause License (and the licenses of the libraries it bundles,
such as OpenBLAS). The Windows package includes unmodified NumPy wheels for 32-bit
Python 3.8 and 3.15 under autozhuyin/vendor/; the Linux installer downloads the
matching wheel from PyPI when the system has no NumPy. Each copy keeps its license
files in its numpy-*.dist-info folder.
