自動注音 AutoZhuyin（Windows 測試版）
=====================================

用大千注音鍵盤直接打字，不用切換中英文，輸入法會自動判斷你打的是注音還是英文。

  按鍵： ji3 hello world su3cl3 （最後按空白）
  輸出： 我hello world 你好


安裝
----
也可以改用 AutoZhuyin-Windows-<版本>-setup.exe（實驗功能）：會自動安裝需要的 PIME，不用做下面的步驟。
這個 zip 是手動安裝版：

1. 先安裝 PIME 輸入法框架（免費、開源）：
   https://github.com/EasyIME/PIME/releases
   下載 PIME-x.x.x-setup.exe 安裝（預設選項即可）。

2. 解壓縮這個 zip，在 install.bat 上按右鍵 →「以系統管理員身分執行」。

3. 設定 → 時間與語言 → 語言與地區 → 中文(台灣) → 語言選項 → 新增鍵盤，
   加入「自動注音 AutoZhuyin」。如果清單裡沒有，重新開機一次。

4. 用 Win + 空白鍵 切換到自動注音。

安裝時被防毒軟體擋下？
自動注音沒有花錢買微軟的數位簽章，Windows 內建防毒有時會誤判成病毒。
確定是從本專案 GitHub 下載的，可以暫時關閉防護，裝完再打開：

  1. 開始 → 輸入「Windows 安全性」→ 打開
  2. 點「病毒與威脅防護」
  3. 「病毒與威脅防護設定」下面點「管理設定」
  4. 把「即時保護」關掉（跳出詢問時按「是」）
  5. 檔案被刪掉的話重新解壓縮，再執行安裝
  6. 裝完回到同一個畫面，把「即時保護」打開
     （忘記也沒關係，Windows 過一陣子會自動打開）

其他防毒軟體請在它們的主畫面暫停防護，或把這個資料夾加入信任清單。


使用方式
--------
  空白        注音：一聲；音節打完時送出中文。英文：送出單字加空白
  Enter       送出目前組字
  Tab         判斷錯了？按 Tab 把最後一段在中／英之間翻轉，輸入法會記住這次修正
  ← →         在組字區移動游標，選要改哪個字；游標在中間時直接打注音
              會插入新字，Backspace 刪掉游標前的字
  ↓           開啟游標前那個字或詞的候選字，按數字鍵 1–9 選字；
              選過的字會被記住，下次優先出現
  Esc         取消組字
  單按 Shift  切換英文模式（按鍵直接送出、保持小寫、沒有底線，工作列圖示變成 A），
              再單按一次回到中英自動判斷，會出現「英文」／「中英自動」小提示；
              打到一半時按，同 Tab 翻轉最後一段
  Shift+字母  打大寫字母（也會強制英文）
  < > ? ! :   中文語境下自動變成全形 ，。？！：
  標點        剛打的標點會先留在組字區：Tab 切換全形／半形，↓ 選別的符號
              （例如「 可以換成 『（【〔《〈），打下一個字才送出
  ` + 標點    強制全形標點，例如 `< 或 `, = ，  `. = 。  `/ = ？  `; = ；
  Ctrl + 標點 直接打出全形標點：Ctrl+; = ；  Ctrl+' = 、  Ctrl+, = ，  Ctrl+. = 。  Ctrl+/ = ？
  \           中文後面按 \ = 、
  要打聲調才出字  選單裡的開關（預設開啟）：沒打聲調的音節維持注音符號；還沒打聲調時
              補打的注音會蓋掉前面的（ㄒㄧㄥ 再打 ㄩˊ → ㄒㄩㄥˊ 雄）
  候選字顯示符號與 emoji  選單裡的開關（預設開啟）：「星」「乘」「圓」這類候選字後面接著符號
              （星 → ★☆、乘 → ×），「笑」「貓」後面接著 emoji（笑 → 🤣🥰😼），每頁最多 2 個；
              「上下左右」後面接著箭頭 ↑↓←→
  ` 再按空白  打開符號表（、；「」『』《》…→ ○ ★ 等），數字鍵或方向鍵加 Enter 選字；
              前面是英文時改按 ` 再按 ↓
              `' = 、  `[ `] = 「」  `( `) = （）  `! = ！
              ` 後面接其他鍵就是普通的反引號

注音符號的順序打錯也沒關係，例如 ㄧㄒㄠˇ 會自動變成 ㄒㄧㄠˇ（小）。


AI 選字
-------
用中研院 CKIP 的繁體中文小型語言模型，看前後文挑同音字（他跑「得」很快、請你「再」說一次），
完全在本機運算，不連網。在工作列的輸入法圖示上按右鍵（或語言列的設定按鈕）可以選：
  AI 選字：關閉／省電／標準（預設）／高品質
  系統忙碌時自動暫停 AI（預設開啟：CPU 很忙時暫停，省電模式時改用省電）
高品質模型（選擇性，下載約 200 MB）：錯字比標準少約四成，但執行時多佔約 400 MB 記憶體。
安裝時在「選擇元件」勾選「AI 高品質模型」，或之後在選單選「下載高品質模型」；不要了可以選
「移除高品質模型」。沒下載時「高品質」和「標準」一樣。
選單裡會顯示目前狀態。電腦比較慢時建議用「省電」，運算太慢時也會自動暫停一分鐘。


回報問題
--------
請告訴我：
  - 按了哪些鍵（例如 2;3）
  - 預期打出什麼、實際出現什麼
  - 在哪個程式裡打字（Word、LINE、Chrome…）

自訂詞：%APPDATA%\PIME\autozhuyin\user-phrases.txt
  （輸入法選單的「編輯自訂詞…」會用記事本打開，存檔後下次切換到輸入法時生效）
  每行一個詞，格式：ㄗˋ-ㄉㄨㄥˋ-ㄓㄨˋ-ㄧㄣ 自動注音 -4

解除安裝：在 uninstall.bat 上按右鍵 →「以系統管理員身分執行」。
